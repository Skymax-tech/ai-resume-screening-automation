# AI Resume Screening Automation

## 📌 Project Overview

An AI-powered recruitment workflow designed to automate the initial screening of job applications for a Junior Data Analyst role.

The system collects candidate information, stores the application in Airtable, evaluates the candidate using AI, saves the evaluation, and notifies HR when a candidate achieves a high score.

## 🔄 Workflow

Candidate submits application
↓
Application captured through form
↓
Candidate information saved to Airtable
↓
AI evaluates candidate against the Junior Data Analyst criteria
↓
AI returns:
- Overall Score /100
- Strengths
- Weaknesses
- Recommendation
↓
Evaluation saved to Airtable
↓
High-scoring candidates trigger an HR notification

## 🛠️ Tools Used

- n8n
- Airtable
- Google Gemini AI
- Gmail
- Telegram
- Structured Output Parser

## 🤖 AI Evaluation

The AI evaluates candidates based on their suitability for a Junior Data Analyst position.

The evaluation includes:

- Overall candidate score
- Key strengths
- Identified weaknesses
- Interview or rejection recommendation

## 🔔 Automated HR Notification

Candidates achieving a high evaluation score can trigger an automated Telegram notification to HR.

This allows recruiters to quickly identify promising candidates without manually reviewing every application.

## 🎯 Business Value

This workflow helps reduce repetitive recruitment tasks by automating the initial screening process.

It can help businesses:

- Save recruiter time
- Standardize initial candidate evaluation
- Organize applicant information
- Identify high-potential candidates faster
- Reduce manual administrative work

## 🔐 Privacy & Security

This repository contains a portfolio demonstration of the workflow.

No real candidate information, passwords, API keys, authentication credentials, or private business data are included.
